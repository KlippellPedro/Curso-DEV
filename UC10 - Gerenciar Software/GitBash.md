# GitBash

### Configurações iniciais

**git init** = inicia o git

**git congig user.name KlippellPedro** = configura o nome do git que quero usar

**git congig user.email pnklippel@gamil.com** = configura o email do git que quero usar


### Manejar arquivos no gitbash

**mkadir** + nome da pasta = cria uma pasta

**echo>** + nome do arquivo.extenção (ex: teste.py) = cria um arquivo na pasta

**rm** + nome do arquivo.extenção = deleta um arquivo

**rm -r** + nome da pasta = deleta uma pasta
